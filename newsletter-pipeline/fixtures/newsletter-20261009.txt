TIPS
1. Check your AI judge against human labels (from Hamel Husain (@HamelHusain))
   WHAT: A judge is a model that grades outputs. It can usually be the same model as your main task.
   HOW: Label a held-out test set by hand. Measure how often the judge agrees on passes and fails.
   WHY: Agreement with people matters most. Try a different judge model only if agreement stays low.
   Read more: https://hamel.dev/blog/posts/evals-faq/can-i-use-the-same-model-for-both-the-main-task-and-evaluation.html
   Post on X: https://x.com/HamelHusain/status/2108210834988032433

2. Run agent code in one sandbox on every OS (from Simon Willison (@simonw))
   WHAT: MXC is an open-source Microsoft library. It runs untrusted code, such as model output, in a sandbox.
   HOW: Install the Rust, .NET or Node SDK. Set allowed paths and network rules in a JSON policy.
   WHY: One setup works on Windows, macOS and Linux. Each system uses its own built-in sandbox.
   Read more: https://github.com/microsoft/mxc
   Post on X: https://x.com/simonw/status/2108216753604248000

3. Grade each agent run with several typed questions (from Harrison Chase (@hwchase17))
   WHAT: Jev, a fast decision model from TypeSafe, can judge agent runs in LangSmith, a tracing tool.
   HOW: Open the Evaluators tab in a LangSmith tracing project. Ask difficulty and correctness as separate questions.
   WHY: Each question gets its own typed answer in one pass. This tells you more than one pass/fail score.
   Read more: https://www.langchain.com/blog/jev-is-now-available-in-langsmith-evals
   Post on X: https://x.com/hwchase17/status/2108453917277254058

4. Fine-tune on longer text with less GPU memory (from @QGallouedec via @huggingface)
   WHAT: TRL is a Hugging Face library to fine-tune models. Version 1.15 adds a memory-saving step by default.
   HOW: Run pip install -U trl. Rerun your DPO or GRPO job with longer examples on a Linux GPU.
   WHY: At 8,192 tokens, peak GPU memory drops 52% to 82%. DPO fits 59,392 tokens, not 10,240.
   Read more: https://github.com/huggingface/trl/releases/tag/v1.15.0
   Post on X: https://x.com/QGallouedec/status/2108468004128424042

5. Build trust in agent output before you scale up (from Lauren Tan (@poteto))
   WHAT: Trusted agents let one person ship far more work. Volume only scales after you trust the output.
   HOW: List your ongoing work streams. Give each stream an agent and checks that you trust.
   WHY: Without checks that you trust, you cannot review more work. Trust lets your output grow.
   Read more: https://x.com/poteto/status/2108290818746528017
   Post on X: https://x.com/poteto/status/2108290818746528017
