From Harrison Chase (@hwchase17)

HOWOpen the Evaluators tab in a LangSmith tracing project. Ask difficulty and correctness as separate questions.

📈
Fine‑tune on longer text with less GPU memory
From @QGallouedec via @huggingface
WHATTRL is a Hugging Face library to fine‑tune models. Version 1.15 adds a memory‑saving step by default.
HOWRun pip install -U trl. Rerun your DPO or GRPO job with longer examples on a Linux GPU.
WHYAt 8,192 tokens, peak GPU memory drops 52% to 82%. DPO fits 59,392 tokens, not 10,240.

🤖

From Lauren Tan (@poteto)
WHATTrusted agents let one person ship far more work. Volume only scales after you trust the output.

WHYWithout checks that you trust, you cannot review more work. Trust lets your output grow.
